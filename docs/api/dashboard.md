# Dashboard API

Base: `/api/v1/dashboard`

## Endpoints dự kiến

- `GET /api/v1/dashboard/summary`
- `GET /api/v1/dashboard/attendance`
- `GET /api/v1/dashboard/care`
- `GET /api/v1/dashboard/tasks`

## Filter dự kiến

- thời gian
- CS / CSGroup
- teacher
- class
- package
- level/status nếu schema/spec có

Tất cả aggregate phải enforce data scope tại backend.
