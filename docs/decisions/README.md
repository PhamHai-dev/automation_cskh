# Architecture Decision Records (ADR)

Dùng ADR cho quyết định kỹ thuật/nghiệp vụ quan trọng cần lưu lý do và trade-off.

Không cần ADR cho mọi thay đổi nhỏ. `docs/decisions/summary.md` là danh sách quyết định tổng hợp; ADR cung cấp chi tiết cho quyết định lớn.

Tên file gợi ý:

`ADR-001-ten-quyet-dinh.md`

Dùng template `ADR-TEMPLATE.md`.
